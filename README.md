# Raycasting Simulation

A C++ raycasting simulation built with [raylib](https://www.raylib.com/) to explore 2D geometry, vector mathematics, collision detection, ray-wall intersection, and pseudo-3D rendering from scratch.

## Current Progress

* Resizable raylib window
* Arena and wall system
* Player movement and rotation
* Player triangle rendering
* Player hitbox
* Basic collision groundwork
* Debug visualization

## Planned

* Ray generation
* Ray-wall intersection
* Field of view
* Distance calculations
* Pseudo-3D wall projection
* Textures
* Procedural map generation
* Performance improvements

## Tech Stack

* C++
* raylib
* MinGW / GCC
